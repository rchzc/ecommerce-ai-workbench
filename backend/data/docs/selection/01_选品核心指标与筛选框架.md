# 选品核心指标与筛选框架

## 一、初筛指标（不满足直接淘汰）

| 指标 | 健康区间 | 说明 |
|------|---------|------|
| 月销量 | 头部链接 ≥ 1500 单 | 低于此说明市场容量不足 |
| 客单价 | 15-60 美元 | 太低利润覆盖不了广告和物流 |
| 竞品数量 | 前 20 名中 ≤ 8 个强竞品 | 强竞品指 Review > 2000 且评分 > 4.5 |
| 评分天花板 | 头部均分 ≤ 4.4 | 均分过高说明已被大卖占据 |
| 重量体积 | 单件 < 2kg，体积小 | 直接决定头程和 FBA 费用 |

## 二、利润测算（必做，不能只看毛利）

利润 = 售价 - 采购成本 - 头程运费 - FBA 费 - 佣金(15%) - 广告费 - 退货损耗

- 广告费按售价的 12%-18% 预留（新品期更高，可能到 25%）
- 退货损耗按 3%-8% 预留（服饰类可达 15%）
- **净利润率低于 15% 的品不要做**，抗风险能力太差

## 三、筛选流程

1. 用工具批量拉取类目 Top100，按销量和上架时间排序
2. 筛选上架 < 12 个月但已进入 Top50 的新品 —— 说明这个类目还有机会
3. 逐个过初筛指标
4. 剩下 5-10 个做人工利润测算
5. 最终选 1-3 个做小批量测款

## 四、测款原则

- 首单 300-500 件，不要压大货
- 测款周期 30-45 天，看自然出单和转化率
- 转化率低于类目均值 70% 的，果断放弃，不要恋战
