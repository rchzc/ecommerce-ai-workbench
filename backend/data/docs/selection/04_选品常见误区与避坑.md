# 选品常见误区与避坑清单

## 误区一：只看销量不看利润

**典型表现**：看到某品月销 5000 单就跟风。
**问题**：没算清楚广告费和退货率，卖得越多亏得越多。
**正确做法**：先算净利率，低于 15% 直接淘汰。

## 误区二：忽视专利和合规

**高危品类**：
- 外观专利：造型独特的家居用品、玩具
- 发明专利：带电子功能的产品
- 认证要求：儿童用品（CPC）、电子（FCC/CE）、食品接触（FDA）

**避坑方法**：
1. 上架前查 USPTO 和欧盟外观专利库
2. 要求供应商提供现有认证文件
3. 避开知名品牌的外观和配色（即使没专利也可能被投诉）

## 误区三：过度依赖单一供应商

**风险**：工厂涨价、断供、品质波动都会致命。
**做法**：核心品类至少备选 2 家供应商，同品质不同区域。

## 误区四：进入强垄断类目

**识别信号**：Top10 全是同一品牌，或 Review 数普遍 > 5000。
**后果**：新品广告再猛也打不动，自然位永远在第五页。
**做法**：转去找竞争分散的细分品类，哪怕是更小的市场。

## 误区五：拿货价压太低导致品质崩盘

**典型**：为了多 5 个点利润，选了报价低 20% 的工厂。
**后果**：差评率上升 → 转化率下降 → 广告费上升 → 实际利润更低。
**做法**：品质成本必须预留，差评的隐性成本远高于采购省下的钱。

## 误区六：没有测款就压大货

**正确节奏**：首单 300-500 件测款 → 数据达标 → 二次补货 2000-5000 件。
**测款不达标的表现**：30 天内自然出单 < 50 单，或转化率 < 类目均值 70%。
