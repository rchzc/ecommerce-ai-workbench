# 市场容量与竞争度评估方法

## 一、市场容量测算

用 Top20 链接月销量求和，再乘以经验系数：

- 头部集中型类目（Top3 占 60%+）：系数 1.3
- 长尾分散型类目（Top20 差距不大）：系数 2.0

**判断标准**：类目总月销量 < 10000 单的，容量偏小，进去也是分残渣。

## 二、竞争度量化

### 1. Review 壁垒
统计 Top10 的平均 Review 数：
- < 500：低壁垒，新品有机会
- 500-2000：中等壁垒，需要至少 6 个月积累期
- \> 2000：高壁垒，除非有差异化产品，否则不要碰

### 2. 品牌集中度
Top20 中同一品牌占据的坑位数：
- ≤ 3：分散，机会大
- 4-8：中等
- \> 8：已被大卖垄断

### 3. 价格带分布
画出 Top20 的价格分布，找**价格真空带** —— 没有人在做的价格区间。
常见真空带：中高端（比主流贵 30%-50% 但品质明显更好）。

## 三、趋势判断

- 用 Google Trends 看 3 年曲线，区分「上升趋势」「季节波动」「衰退期」
- 只进上升趋势和稳定需求的类目，衰退期类目再便宜也不要碰
- 季节性品类要提前 3-4 个月备货，否则赶不上销售窗口

## 四、差异化机会点

在以下维度找突破，而不是做同质化产品：
1. 功能组合（把两个常用功能合一）
2. 材质升级（同类产品用更好的材料）
3. 场景细分（针对特定使用场景优化）
4. 包装与开箱体验
5. 配件与耗材的完整性
