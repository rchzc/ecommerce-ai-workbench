# 德国 VerpackG 包装法（德国 EPR 强制）

> VerpackG 全称 Verpackungsgesetz（德国《包装法》）。
> 2019 年 1 月 1 日生效，是德国 EPR 体系中**强制 + 双罚**最严的一环。
> 不只是电子产品，**任何有外包装的产品到德国都必须注册**。

## 一、强制对象

任何**最终消费者**使用的包装（含运输外箱、缓冲物、单件塑料袋、标签纸）都计入：

- 外纸箱（电商发货箱）
- 内填充物（气泡袋 / 泡沫 / 纸张）
- 商品包装（彩盒 / 贴纸 / 说明书）
- 透明袋 / 自封袋
- 商品吊牌 / 标签

**B2B 整柜 / 大宗物流不适用**，但凡涉及"德国消费者"场景全部适用。

## 二、合规三件套

```
LUCID 注册号（公开查询）
  + 至少一家"二元回收系统"签约（如 Interseroh / Grüner Punkt / Reclay / BellandVision）
  + 申报数据：按重量 / 材质季度申报
```

### 关键节点

| 节点 | 要求 | 红线 |
|------|------|------|
| LUCID 注册 | 必须，所有卖家在德国销售都必须 | 没注册 = 包裹无法清关 |
| 系统签约 | 必须选 ≥1 家双元回收系统（Duale System） | 没签约 = 平台可下架 listing |
| 数据申报 | 季度提交包装重量 / 材质 | 漏报罚款 1 万 € 起 |

## 三、LUCID 注册流程

1. 进入 https://lucid-verpackungsregister.de/en
2. 选择 "Manufacturer / Distributor" 角色
3. 填写品牌名、SKU 范围、联系人
4. 获得 LUCID 号（9 位数字 + 字母）
5. 把 LUCID 号填回亚马逊 / Shopify 后台 + Listing 详情页

**LUCID 号是公开查询的**，德国消费者和竞争对手都能查到。未注册的法律后果：

- 最高 20 万 € 罚款
- 德国 Amazon / Otto / Kaufland 平台主动下架
- 海关可拒绝清关

## 四、双元回收系统对比

| 系统 | 适合 | 报价区间（每 SKU/年） |
|------|------|---------------------|
| Grüner Punkt（绿点） | 通用所有品类 | €200-500 / SKU 起 |
| Interseroh | 含电子 + 包装 | 综合打包更划算 |
| Reclay BellandVision | 重品类 / 大重量 | 按吨计价便宜 |
| Zentek | 中小卖家友好 | €150-400 / SKU / 年 |

> 选择策略：**SKU 多 / 单 SKU 量小 → 走 Grüner Punkt；SKU 少 / 单 SKU 量很大 → 走 Reclay 按吨。**
> 没有"最便宜"，要按 SKU 画像选。

## 五、亚马逊特殊要求

亚马逊强制要求：

1. 后台填写 LUCID 号（路径：Settings → Account Info → Packaging Information）
2. 没填 = 平台代扣 30% 包装附加费（每个发到德国的产品）
3. 填了但没签约双元系统 = 仍可能被代扣

## 六、合规预算（参考量级）

| 项目 | 一次性 | 年度 |
|------|--------|------|
| LUCID 注册 | €0 | €0 |
| 双元回收系统 | — | €150-500 / SKU |
| 包装重声明 | — | €0（自填） |
| 罚款防御 | — | 远小于 1 万 € / 次 |

## 七、自查清单

- [ ] 在 LUCID 注册了并拿到 9 位 ID？
- [ ] 至少签约 1 家双元系统并付费？
- [ ] 亚马逊后台已填 LUCID 号？
- [ ] Listing 详情页或卖家信息中披露 LUCID 号？
- [ ] 季度申报数据已保留（重量 + 材质）？
- [ ] 所有外箱、缓冲、彩盒都已计入申报？
