# 含电池产品合规：UN38.3 + 磁检 + 头程限制

> 跨境电商含电池品（蓝牙耳机 / 充电宝 / 智能手表 / 电动玩具 / 移动电源）
> 的合规难度排在所有品类**前 3%**。漏一个测试报告 = 整批被退运 + 货代拒收 + 平台下架。
> 本篇覆盖空运、海运、海外仓三种头程场景的完整合规链。

## 一、为什么必须做这些测试

### 1. UN38.3（联合国锂电池运输测试）

**适用范围**：所有含锂电池的产品，无论锂电池是安装在设备内还是随设备附带 / 单独运输。

**8 项必测**（按 UN Manual of Tests and Criteria Part III Section 38.3）：

| 编号 | 测试 | 模拟场景 |
|------|------|----------|
| T1 | 高度模拟 | 货舱气压低（航空运输） |
| T2 | 热冲击 | 温差剧变 |
| T3 | 振动 | 卡车 / 飞机震动 |
| T4 | 冲击 | 跌落 / 撞件 |
| T5 | 外短路 | 端子误接 |
| T6 | 撞击 | 外力撞电池 |
| T7 | 过充电 | 充电器故障 |
| T8 | 强制放电 | 异常放电 |

> **缺一不可**：8 项全部通过才能拿 UN38.3 测试报告（机构出具，常见 CNAS / CMA 资质）。

### 2. 磁检（航空运输 IATA 法规）

含磁铁的产品（磁吸手机壳 / 磁吸充电宝 / 磁性收纳盒）按 IATA Dangerous Goods Regulations（DGR）需做：

- 磁场强度 < 0.00525 Gauss @ 4.5m（450cm 距离规定值）
- 实际：常用"距货物表面 2.1m / 4.5m 测磁场强度 ≤ 0.525 Gauss"判据

**未做磁检 = 空运拒收 / 退运 + 不退运费**。

## 二、不同电池类别的运输规则

### 锂离子电池（Li-ion / 锂聚合物）

| 类型 | 客机禁运（按 IATA PI） | 货机可运（PI 965/966/967） |
|------|----------------------|---------------------------|
| 单独锂电池（PI 965） | **禁** | ✅ 限量 ≤ 35kg / 包（Section II） |
| 随设备安装（PI 966） | 部分允许 | ✅ ≤ 10kg（Section II） |
| 装在设备内（PI 967） | ✅ 允许 | ✅ 无重量限制 |

### 锂金属电池（不可充电纽扣电池 / 锂锰）

| 类型 | 含量限制 |
|------|----------|
| 单独运输 | ≤ 0.3g 锂含量（Section II） |
| 装在设备内 | ≤ 0.3g / 电池 |

> 国内厂家最爱忽略：**纽扣电池也算锂金属**，必须按 UN3090 / UN3091 申报。

## 三、海运路径（推荐方式）

含电池产品走**海运整柜 / 拼箱**可以绕过空运严苛限制。但仍需：

1. UN38.3 测试报告（必须，海运也要）
2. MSDS（Material Safety Data Sheet）化学品安全表
3. 货物包装 Class 9 hazard label（贴"锂电池"标识）
4. 危险品申报（DGD, Dangerous Goods Declaration）

**海运"散货"含电池产品几乎必被查验 + 加收 DGD 费**，建议：
- 量小：拼箱直发 EMS / 国际快递（已含 IATA 申报）
- 量大：整柜海运 + 提前一周预约

## 四、海外仓备货模式

走 FBA / 海外仓的特别要求：

| 平台 | 含电池特殊要求 |
|------|---------------|
| 亚马逊 FBA | 必须先经 Amazon Approved Battery Cell 审核，没过不能入仓 |
| eBay 海外仓 | 仓库需要"危险品仓"资质 |
| Shopify 自建海外仓 | 比照国内电池仓标准（断电 / 防短路存放） |

## 五、合规成本（参考量级）

| 测试 | 一次性 | 周期 |
|------|--------|------|
| UN38.3 全套 | ¥8,000-30,000 | 4-6 周 |
| 磁检报告（IATA） | ¥2,000-5,000 | 1-2 周 |
| MSDS 编制 | ¥500-2,000 / 份 | 1 周 |
| 运输 DGD 申报 | ¥200-800 / 票 | 1 天 |
| 亚马逊电池审核 | ¥0 | 4-8 周 |

> 一个新含电池产品从 0 开始走完合规 ≈ ¥1.5-4 万元 + 3 个月。
> **不做被发现：整批退运 + 平台下架 + 后续所有同 SKU 的货都受影响**。

## 六、Listing 时的合规提示

含电池产品在 Listing 中必须：

- [ ] 五点描述里明确电池容量（mAh）+ 锂含量（g）
- [ ] 标注符合 UN38.3（"UN38.3 Tested"或类似话术）
- [ ] 标注"IATA Compliant"或"Air Transport Approved"
- [ ] 不允许写"可托运上飞机"——这话由买家自己确认航司

## 七、自查清单（出货前必查）

- [ ] UN38.3 报告 + 8 项结果都是 PASS？
- [ ] 磁检 / MSDS / MSDS 是否在有效期（一般为 1 年）？
- [ ] 外箱是否贴 Class 9 锂电池标识？
- [ ] FBA 入仓有 Amazon Battery Cell 审核通过记录？
- [ ] Listing 详情页合规字段齐全？

## 八、一句话总结（给 Listing / Support Agent 用）

> 含电池产品：UN38.3 是入场券，磁检是空运证，FBA 审核是入仓证，三证齐全才能上量。
