# 头程物流渠道对比与选择

## 一、四种主流渠道

| 渠道 | 时效 | 成本 | 适用场景 |
|------|------|------|---------|
| 海运整柜 FCL | 30-45 天 | 最低 | 大批量、非紧急补货 |
| 海运拼箱 LCL | 35-50 天 | 低 | 中小批量常规补货 |
| 空运 | 7-15 天 | 中高 | 紧急补货、高货值 |
| 国际快递 | 3-7 天 | 最高 | 样品、极小批量紧急件 |

## 二、成本结构

### 海运拼箱报价构成
```
总费用 = 海运费（按 CBM）+ 报关费 + 港杂费 + 派送费 + 关税
```
注意问清楚是否**双清包税**（DDP），否则目的港会产生额外费用。

### 空运报价构成
```
计费重 = max(实际毛重, 体积重)
体积重 = 长×宽×高(cm) / 6000
```
抛货（体积大重量轻）走空运极不划算。

## 三、选择决策树

```
是否紧急（< 20 天必须到仓）？
├── 是 → 货值是否 > 运费的 8 倍？
│       ├── 是 → 空运
│       └── 否 → 重新评估是否值得，或分批（急的部分空运）
└── 否 → 体积是否 > 15 CBM？
        ├── 是 → 海运整柜
        └── 否 → 海运拼箱
```

## 四、常见坑

1. **旺季排仓**：9-11 月海运舱位紧张，需提前 2-3 周订舱
2. **体积重陷阱**：轻抛货按体积重计费，成本可能翻倍
3. **隐性费用**：偏远地区派送费、住宅地址附加费、仓储超期费
4. **清关资料不全**：发票、装箱单、申报要素缺一不可
5. **关税预估值偏低**：实际关税可能高于预估，要做足预算

## 五、渠道组合策略

成熟卖家的常规做法：
- 70% 常规补货走海运（低成本）
- 25% 走空运（应对断货风险）
- 5% 走快递（样品和极紧急件）

**永远不要把所有货押在一个渠道上。**
