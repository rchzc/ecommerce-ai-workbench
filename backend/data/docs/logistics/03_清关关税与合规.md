# 清关、关税与合规要点

## 一、清关必备文件

| 文件 | 说明 |
|------|------|
| 商业发票 | 品名、数量、单价、总价、币种 |
| 装箱单 | 每箱的重量、体积、件数 |
| 提单（B/L） | 海运/空运提单 |
| 原产地证 | 部分国家享受关税优惠需要 |
| 认证文件 | 视品类（FCC、CE、CPC 等） |

## 二、申报要点

### 品名申报
- 要具体，不能笼统写`日用品`、`配件`
- 错误申报会导致查验、罚款，甚至列入黑名单

### 货值申报
- **低报有风险**：一旦被查，补税+罚款+影响后续清关
- **高报没必要**：多交税
- 合理做法：按实际成交价申报，保留付款凭证备查

### HS 编码
- 决定关税税率，必须准确
- 同一产品在不同国家 HS 编码可能不同
- 可要求货代提供预归类建议

## 三、关税与税费

| 地区 | 主要税种 |
|------|---------|
| 美国 | 关税（视 HS 编码）+ 州销售税（部分州） |
| 欧盟 | 关税 + VAT（增值税，19%-27%） |
| 英国 | 关税 + VAT（20%） |
| 日本 | 关税 + 消费税（10%） |

**欧盟 IOSS**：货值 ≤ 150 欧的包裹可用 IOSS 简化 VAT 申报。

## 四、高风险品类

- **含电池产品**：需 UN38.3 测试报告，空运限制严格
- **带磁产品**：需磁检报告
- **液体/粉末/膏体**：空运受限，可能需危险品鉴定
- **儿童用品**：需 CPC 认证（美国）、EN71（欧盟）
- **食品接触类**：需 FDA（美国）、LFGB（欧盟）
- **带激光/无线**：需 FDA 认证 / FCC 认证

## 五、合规红线

1. **不要低报货值**：被查一次，后续所有包裹都会被重点查验
2. **不要瞒报品类**：电池当普通货物报，出事货代和卖家都担责
3. **保留所有凭证**：清关文件至少保留 3 年
4. **关注政策变化**：如欧盟 GPSR 新规、美国 UFLPA 法案
