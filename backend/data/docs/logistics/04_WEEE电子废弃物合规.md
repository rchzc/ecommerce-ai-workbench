# WEEE 电子废弃物合规（欧盟 EPR 强制）

> WEEE 全称 Waste Electrical and Electronic Equipment Directive（欧盟 2012/19/EU）。
> 是欧盟 EPR（Extended Producer Responsibility，生产者延伸责任）的核心法规之一。
> 本篇覆盖电子产品（手机壳 / 蓝牙耳机 / 充电器 / 智能穿戴等）进入欧盟的强制合规流程。

## 一、适用对象

只要产品属于"电气电子设备（EEE）"大类（即便不含电池），进入欧盟均受 WEEE 约束。常见跨境品类：

- 手机壳 / 手机支架 / 充电设备
- 蓝牙耳机 / 音箱 / 智能手表
- 厨房小家电（电热水壶 / 咖啡机 / 烤箱）
- 灯具（LED 灯泡 / 装饰灯）
- 电动玩具 / 电动工具

**不含电池也受 WEEE 约束**，这是常被误判的点。

## 二、合规流程

```
1. 海关清关前：WEEE 注册号 + EAR Foundation 注册证明
   ↓
2. 跨境直发：在包裹上加贴 "crossed-out wheeled bin" 标识
   ↓
3. 海外仓备货：当地注册 + 当地回收组织（PRO）签约
   ↓
4. 各成员国分别申报：不能在德国注册就自动覆盖法国 / 西班牙
```

### 关键节点

| 节点 | 要求 | 红线 |
|------|------|------|
| EAR Foundation 注册 | 任何含电子的产品到德国都必须有 | 无注册号 = 货物被扣 / 店铺被封 |
| 跨境小包标识 | 包装贴垃圾桶打叉标（黑标） | 缺标即视为不合规 |
| 欧盟各国单独注册 | 德国、法国、西班牙、意大利、英国分别有体系 | 不能"以德代欧" |

## 三、各国注册机构

| 国家 | 主管 / 体系 | 注册周期 | 备注 |
|------|------------|----------|------|
| 德国 | Stiftung EAR | 4-6 周 | 强制，最严 |
| 法国 | Syderep / Recylum | 4-8 周 | 含电子需注册到 Syderep |
| 西班牙 | RAEE 分会 | 4-6 周 | 不同品类进入不同分会 |
| 意大利 | CdC RAEE | 6-8 周 | 多体系并行 |
| 英国 | WEEE Scheme 注 | 4-6 周 | 脱欧后独立 |

## 四、合规成本（参考量级）

| 项目 | 一次性 | 年度 |
|------|--------|------|
| 德国 EAR 注册 | €150-300 | €80-200 |
| 法国 Syderep | €200-400 | €100-300 |
| 西班牙 RAEE | €150-250 | €80-200 |
| 跨境垃圾桶标贴印刷 | ¥0.05/贴 | — |

> 一年做 WEEE 合规的最低预算 ≈ €450-700（约 ¥3,500-5,500）。
> 不做被发现：欧盟成员国可处以**最高 €10 万 + 收入没收**。

## 五、与 Listing 输出的关联提示

- Listing 五点里**不能**写"包回收 / 我们处理废弃"等承诺——注册责任在卖家自己
- 商品详情页建议明确标注"Environmental Fee Paid"或"WEEE Registration No: DE XXXXX"
- 包装规格里把垃圾桶标贴的尺寸 / 印色列入 BOM，避免漏装

## 六、自查清单（V1）

- [ ] 产品是否属于 EEE 大类？哪怕是配件也算
- [ ] 目标销售国家都注册了对应 EPR 体系？
- [ ] 包装上贴了 crossed-out wheeled bin 标识？
- [ ] Listing 里没有不合规的"免费回收"承诺？
- [ ] 保留了注册证书 / 申报记录至少 3 年？
