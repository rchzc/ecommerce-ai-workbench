# 海外仓与备货管理

## 一、三种模式对比

| 模式 | 时效 | 成本 | 适用 |
|------|------|------|------|
| 平台仓（FBA 等） | 最快（1-3 天） | 较高（仓储+配送费） | 主力销售 |
| 第三方海外仓 | 中（3-7 天） | 中 | 中转、多平台、大件 |
| 自发货 | 慢（7-20 天） | 低 | 测款、长尾、大件 |

## 二、海外仓的核心价值

1. **降低平台仓储费**：长期仓储的单位成本远低于平台仓
2. **灵活调拨**：多平台（亚马逊、独立站、TikTok）共用一个库存池
3. **处理退换货**：退回海外仓检测后二次销售，减少损耗
4. **规避断货**：平台仓限容时，海外仓作为缓冲

## 三、备货量计算

### 基础公式
```
补货量 = (日均销量 × 补货周期 × 安全系数) - 当前库存 - 在途库存
```

- 补货周期 = 生产 + 头程 + 入仓上架
- 安全系数：常规 1.3，旺季 1.6，新品 1.2

### 分阶段策略
- **新品测款**：300-500 件，宁可断货不要压货
- **稳定期**：按公式计算，保持 45-60 天库存
- **旺季前**：备到 90-120 天，防止排仓延误

## 四、库存健康指标

| 指标 | 健康值 | 说明 |
|------|-------|------|
| 库存周转天数 | 45-75 天 | 太高占资金，太低易断货 |
| 库龄 > 90 天占比 | < 15% | 超过会产生长期仓储费 |
| 断货天数 | 0 | 断货后排名恢复极难 |

## 五、呆滞库存处理

库龄 > 180 天的库存要主动处理：
1. 降价清仓（Outlet、秒杀）
2. 捆绑销售（搭畅销品）
3. 转其他站点
4. 批量转卖给清货商（回收 20%-40% 成本）

**越早处理回收率越高，拖到 365 天以上基本只能弃置。**
