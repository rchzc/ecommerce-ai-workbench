# 差评预防与客户关系维护

## 一、差评的根因预防

差评大部分不是客服能解决的，源头在这三处：

1. **预期管理**（占比最高）：主图和描述夸大，实物不符
   → 主图加参照物、尺寸标注、如实描述
2. **产品品质**：次品率、批次波动
   → 供应商管控、发货前抽检
3. **物流体验**：破损、延迟
   → 包装加固、选择稳定渠道

**客服能做的是拦截，不是根治。**

## 二、主动售后拦截

### 时机选择
- 签收后 5-7 天（客户已使用，但还没形成强烈不满）
- 出现异常物流状态时（延迟、派送失败）

### 内容要点
1. 确认使用是否正常（不是要好评）
2. 提供使用技巧
3. 明确告知联系方式和问题响应时限
4. **绝不索取好评**（违反平台规则）

### 合规做法
- 可以：`有任何问题请先联系我们，我们承诺 24 小时内响应`
- 不可以：`给五星好评返现 10 美元`

## 三、客户分层维护

| 层级 | 特征 | 维护方式 |
|------|------|---------|
| 高频复购 | 买过 3 次以上 | 新品优先试用、专属折扣 |
| 单次高客单 | 客单价高 | 定期关怀、问卷调研 |
| 普通客户 | 买过 1 次 | 邮件营销、节日问候 |
| 有过投诉 | 处理过问题 | 重点跟进，转化成功后忠诚度高 |

**处理得当的投诉客户，忠诚度往往高于从未出问题的客户。**

## 四、邮件/消息营销（合规版）

可以做：
- 新品通知（针对已购客户）
- 使用技巧、保养建议
- 节日问候
- 会员专属折扣

不能做：
- 索取好评
- 诱导修改评价
- 频繁骚扰（每月不超过 2 次）

## 五、指标监控

每周看这 3 个数：
1. 差评数量和差评率趋势
2. 客服首次响应时长（目标 < 12 小时）
3. 问题一次解决率（目标 > 80%）

差评率突然上升要立即排查：是不是某个批次出问题了。
