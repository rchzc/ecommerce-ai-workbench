# 退款退货与纠纷处理

## 一、退款决策原则

先算一笔账：
```
处理成本 = 退款金额 + 物流成本 + 可能的差评损失
差评损失 ≈ 单次差评导致的转化率下降 × 月销量 × 客单价 × 利润率
```

**大多数情况下，痛快地退款比扯皮更划算。** 一个差评的隐性损失远超退款金额。

## 二、分场景处理

| 场景 | 处理方式 | 是否要退货 |
|------|---------|-----------|
| 未收到货 | 全额退款或补发 | 否 |
| 收到破损 | 退款或补发 | 低货值不退，高货值要退 |
| 不想要了 | 退款（平台通常强制） | 是 |
| 与描述不符 | 退款 + 承担退货运费 | 是 |
| 质量问题 | 退款或换新，运费我们承担 | 视金额 |

## 三、退货地址设置

- 优先使用平台仓退货或海外仓地址，**不要让客户退回国**（运费比货值还高）
- 高货值商品可以要求退回检测后再退款
- 明确在政策里写清退货地址，避免客户找不到

## 四、纠纷（A-to-Z / Chargeback）应对

### 平台纠纷
1. 在时限内响应（通常 3-7 天）
2. 准备证据：发货证明、物流签收记录、沟通记录
3. 说明已提供的解决方案
4. 如果是我们的问题，直接认责并退款，争取不影响账户指标

### 信用卡拒付（Chargeback）
1. 收集所有证据：订单、签收证明、沟通记录
2. 在时限内提交申诉
3. 成功率不高，重点是预防：
   - 发货必须有签收记录
   - 高价值订单要求签名确认
   - 及时响应客户问题，避免客户直接找银行

## 五、预防优先

降低退款率的产品和运营侧动作：
1. 主图和描述准确，不夸大（预期管理是根本）
2. 包装加固，减少运输破损
3. 发货前质检，拦截次品
4. 说明书清晰，减少`不会用`导致的退货
5. 发货后主动告知物流信息

## 六、退款率红线

- 退款率 > 10%：产品或服务存在系统性问题，必须整改
- 退款率 5%-10%：警戒，分析退款原因分布
- 退款率 < 3%：健康
