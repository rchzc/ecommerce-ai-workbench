# 售后话术与沟通原则

## 一、沟通四原则

### 1. 先共情，再解决
不要在客户情绪激动时讲道理。先认可他的感受，再谈方案。

- 错误：`这是物流公司的责任，我们也没办法`
- 正确：`让您等这么久真的很抱歉，我现在就为您处理`

### 2. 给出具体方案，不要推诿
- 错误：`请您联系物流公司查询`
- 正确：`我已经为您安排补发，预计 3 天内发出，单号稍后发给您`

### 3. 不承诺超出政策范围的事
**绝对不能说**：
- `一定给您全额退款`（超出了政策范围）
- `私下转账给您补偿`（违反平台规则，可能导致封店）
- `保证不会有下次`（无法保证）

### 4. 留痕
所有承诺都要落在站内信或邮件里，方便后续追溯。

## 二、常见场景话术要点

### 物流延迟
1. 道歉 + 说明当前物流状态
2. 给出预计到达时间
3. 提供选项：等待 / 补发 / 退款
4. 主动提出补偿（小额优惠券或下次折扣，在政策允许范围内）

### 产品破损
1. 道歉，不追问责任
2. 要求提供照片（用于向物流或供应商索赔，但不要显得在怀疑客户）
3. 直接补发或退款，让客户选择

### 产品不会用
1. 提供图文或视频指导
2. 耐心分步说明
3. 确认是否解决
4. 感谢反馈（这类客户最容易转成好评）

### 要求超政策补偿
1. 表达理解
2. 说明我们能做什么（政策范围内的最大方案）
3. 解释为什么不能做（而不是简单拒绝）
4. 提供替代方案

## 三、语气与格式

- 用短句，分段清晰，不要一大段
- 每条消息只讲一件事，方便客户阅读
- 结尾留出继续沟通的入口：`如果还有问题随时联系我`
- 不要用模板感太强的套话，要提及客户的具体情况

## 四、升级判断

以下情况立即转人工主管：
- 客户威胁要给差评或投诉到平台
- 涉及人身伤害或安全问题
- 单笔金额超过授权额度
- 客户已经重复联系 3 次以上
