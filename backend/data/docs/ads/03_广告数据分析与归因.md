# 广告数据分析与归因

## 一、核心指标及诊断

| 指标 | 计算 | 异常含义 |
|------|------|---------|
| CTR 点击率 | 点击/曝光 | 低 → 主图/标题/价格有问题 |
| CVR 转化率 | 订单/点击 | 低 → Listing/评分/价格有问题 |
| ACOS | 花费/广告销售额 | 高 → 出价过高或词不精准 |
| TACOS | 花费/总销售额 | 衡量整体广告依赖度 |

## 二、诊断决策树

```
ACOS 过高
├── CTR 低（< 0.4%）
│   └── 问题在主图和标题 → 优化主图、标题、价格
├── CTR 正常但 CVR 低（< 8%）
│   └── 问题在 Listing 和评分 → 优化五点、A+、想办法提评分
└── CTR、CVR 都正常
    └── 问题在出价和词 → 降价、否词、优化结构
```

## 三、TACOS：比 ACOS 更重要的指标

TACOS = 广告花费 / **总**销售额（含自然单）

- TACOS 下降 = 自然单占比上升 = 广告在起作用（带动排名）
- TACOS 稳定在 10%-15% 是健康状态
- TACOS 持续 > 25% 说明过度依赖广告，产品缺乏自然流量

**新品期 TACOS 高是正常的，关键看它是否随时间下降。**

## 四、归因注意事项

1. **广告单 ≠ 全部由广告带来**：很多用户先点广告看，之后从自然位下单
2. **看 7 天归因窗口**，不要只看当天
3. **新品期要看整体趋势**，不要被单日数据干扰
4. **对比要同口径**：同比、环比要在同一时间段对比

## 五、周报该看什么

每周固定看这 5 个数：
1. 总花费和总销售额
2. ACOS 和 TACOS 的变化趋势
3. Top10 花费词的产出
4. 新增的搜索词机会
5. 需要否定的词

不要沉迷于日报的波动，看周趋势才有意义。
