# ACOS 与广告结构优化

## 一、理解 ACOS

ACOS = 广告花费 / 广告销售额

**关键**：ACOS 不是越低越好，要看它和毛利率的关系。

- 盈亏平衡 ACOS = 毛利率
- ACOS < 毛利率：广告盈利
- ACOS > 毛利率：广告亏损，但如果能带动自然单，可能是值得的战略亏损

## 二、健康区间参考

| 阶段 | 合理 ACOS | 说明 |
|------|----------|------|
| 新品期（0-30 天） | 40%-80% | 用钱换数据和排名 |
| 成长期（1-3 月） | 25%-40% | 优化结构，降低无效花费 |
| 成熟期（3 月+） | 15%-25% | 接近或低于毛利率 |
| 清仓期 | 视目标而定 | 目标是回款，不是利润 |

## 三、广告结构： campaigns 分层

### 自动广告
- 目的：跑词，发现机会
- 预算：小（总预算 20%）
- 长期保留，但定期否词

### 手动精准（核心词）
- 目的：抢核心流量
- 出价高，预算集中
- 只放 3-5 个最核心的词

### 手动广泛/词组
- 目的：捡漏长尾
- 出价低，预算小
- 定期从搜索词报告里提取好词，提到精准组

### 商品投放（ASIN 定向）
- 打竞品页面
- 优先选评分比你低、价格比你高的竞品

## 四、结构优化动作

1. **每周否词**：搜索词报告里，点击 > 10 且零转化的词全部否定
2. **词分层**：表现好的词单独建组，给更多预算
3. **控预算**：不要所有组都给预算，集中给产出最高的 20%
4. **调出价**：不要一次调超过 20%，否则流量会剧烈波动

## 五、常见错误

- 新品一上来就打大词（预算烧光没转化）
- 只看 ACOS 不看总利润
- 频繁调价（每次调整需要 3-5 天数据沉淀）
- 否定词加太多导致没曝光
