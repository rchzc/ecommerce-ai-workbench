# 差评处理与预防机制

## 一、差评分级响应

| 类型 | 响应时限 | 处理方式 |
|------|---------|---------|
| 物流破损 | 24 小时内 | 直接补发或退款，不争执 |
| 产品缺陷 | 24 小时内 | 道歉 + 换新 + 追问具体批次 |
| 使用不当 | 48 小时内 | 礼貌解释 + 提供使用指导 |
| 恶意差评 | 尽快 | 收集证据，向平台申诉 |

## 二、回复模板原则

1. **先共情再解决**：`非常抱歉给您带来不便` 开头，不要辩解
2. **给出具体方案**：不要说`请联系客服`，直接说`我们已安排补发`
3. **公开回复要简短**：详细方案走站内信，公开回复让其他人看到你的态度
4. **绝不与客户争执**：赢了争论输了客户

## 三、预防机制（比处理更重要）

### 1. 售后卡（合规版本）
- 不要写`给好评返现`（违规）
- 可以写`有任何问题请先联系我们，我们承诺 X 小时内解决`
- 提供清晰的联系方式

### 2. 包装内附快速上手卡
很多差评源于`不会用`，一张图文快速上手卡能显著降低。

### 3. 主动售后
发货后 7 天发一封使用关怀邮件（平台允许的话）：
- 确认是否收到
- 提供使用技巧
- 有问题引导联系客服而非直接留差评

### 4. 品质批次追溯
记录每批货的差评率，一旦某批次异常升高，立即暂停该批次发货并追查供应商。

## 四、差评率红线

- 差评率（1-2 星占比）> 8%：产品存在系统性问题，必须整改
- 差评率 5%-8%：警戒，需要分析根因
- 差评率 < 3%：健康

**注意**：差评率上升会直接拉低转化率，进而推高广告成本，形成恶性循环。
