# 评论情感分析与痛点归类

## 一、情感分级

不要简单二分（好评/差评），按这个粒度：

| 星级 | 情感 | 处理方式 |
|------|------|---------|
| 5 星 | 强正面 | 提炼卖点，用于 Listing |
| 4 星 | 弱正面 | 找可改进点 |
| 3 星 | 中性 | 找预期落差 |
| 1-2 星 | 负面 | 紧急处理，归类根因 |

## 二、痛点归类框架

把每条负面评论归到以下 5 类之一，便于统计优先级：

1. **产品功能问题**：不工作、效果不达标、参数虚标
2. **产品品质问题**：做工差、材料差、易损坏
3. **预期管理问题**：描述与实物不符、尺寸不符预期
4. **物流包装问题**：运输破损、包装简陋、缺件
5. **使用体验问题**：安装复杂、说明书看不懂、操作繁琐

## 三、关键区分：产品问题 vs 预期管理问题

这是最有价值的判断，因为解法完全不同：

| 类型 | 特征 | 解法 |
|------|------|------|
| 产品问题 | 用户按说明正确使用，但产品达不到 | 改产品 / 换供应商 |
| 预期管理问题 | 产品本身没毛病，但用户期望错了 | **改 Listing 描述** |

**典型预期管理问题**：
- `比想象的小` → 主图缺少参照物，加尺寸对比图
- `不知道要自己组装` → 标题或五点没写清楚
- `颜色和图片不一样` → 图片色差或灯光问题

**这类问题改 Listing 就能解决，成本远低于改产品。**

## 四、统计与优先级

按「出现频次 × 影响程度」排序：

优先级 = 出现次数 × 权重（功能问题 3.0 / 品质 2.5 / 预期 1.5 / 物流 1.0 / 体验 0.8）

只处理排前 3 的痛点，不要试图一次解决所有问题。
