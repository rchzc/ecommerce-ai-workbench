# 关键词挖掘与布局策略

## 一、关键词来源

1. 平台搜索框下拉词（最真实的搜索行为）
2. 竞品标题和五点描述
3. 竞品评论里的用户原话（最贴近真实表达）
4. 关键词工具（Helium10、卖家精灵等）
5. 广告报表里的「客户搜索词」

**优先级**：广告搜索词 > 评论原话 > 搜索下拉 > 工具词库

## 二、关键词分类

| 类型 | 特征 | 用法 |
|------|------|------|
| 核心词 | 搜索量大、竞争大 | 放标题前段 |
| 精准长尾 | 搜索量中、转化高 | 放五点和后台 ST |
| 泛长尾 | 搜索量小、竞争小 | 广告低价捡漏 |
| 场景词 | 带使用场景 | A+ 页面和描述 |

## 三、布局位置

1. **标题**：核心词 + 主要长尾，前 60 字符必须包含主词
2. **五点描述**：每条开头放大写关键词
3. **后台 Search Terms**：填标题里没放下的长尾，不重复标题已有的
4. **A+ 页面**：场景词和疑问词
5. **产品描述**：自然融入，不要堆砌

## 四、新品期关键词策略

新品权重低，直接抢大词必亏。正确做法：

1. 第一周：只投长尾精准词（竞争小，容易出单）
2. 出 20-30 单后：逐步加入中等竞争词
3. 累积 100+ 单、评分稳定后：开始冲核心大词
4. 全程监控广告报表的搜索词，否定不相关的

## 五、常见错误

- 后台 ST 重复标题已有的词（浪费字段）
- 堆砌不相关的热词（会被判违规，且转化率差）
- 只看搜索量不看竞争度
- 一次性上所有词（预算分散，哪个都投不好）
