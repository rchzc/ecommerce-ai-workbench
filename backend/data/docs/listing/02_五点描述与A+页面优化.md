# 五点描述与 A+ 页面优化

## 一、五点描述的黄金结构

每条卖点按这个顺序写：

`【大写关键词开头】+ 具体说明 + 用户收益 + 场景`

示例：
`【12 小时保温】采用双层真空不锈钢内胆，早晨装的热水到晚上仍是温的，适合长时间户外工作和通勤使用。`

## 二、五条的分配逻辑

| 位置 | 应该讲什么 |
|------|-----------|
| 第 1 条 | 最强卖点 / 解决最大痛点 |
| 第 2 条 | 核心功能参数 |
| 第 3 条 | 材质、工艺、品质证明 |
| 第 4 条 | 使用场景 / 适用人群 |
| 第 5 条 | 售后保障 / 包装清单 |

**第 1 条最重要**：移动端只显示前 2-3 条，后面要点击才能展开。

## 三、写法技巧

1. **用数字说话**：`快 3 倍`、`省 50% 空间`、`续航 12 小时`
2. **讲收益不讲参数**：不要写`容量 500ml`，要写`一次装满够喝半天`
3. **回应差评**：把竞品差评里高频吐槽的点，在卖点里明确回应
4. **场景化**：让用户能想象自己使用的画面

## 四、A+ 页面要点

### 模块选择
- 品牌故事模块（适合有品牌调性的）
- 产品对比表格（适合多 SKU）
- 场景图 + 文字说明（适合功能型产品）
- FAQ 模块（解决常见疑虑）

### 图片规范
- 尺寸 970×600 或 970×300
- 文字占比不超过 25%，否则可能被拒
- 每张图讲清楚一件事，不要信息过载

### 高转化模块顺序
1. 主视觉 + 一句话核心价值
2. 核心功能拆解（3-4 个）
3. 参数表格
4. 使用场景图
5. 品质证明（认证、检测报告）
6. FAQ
