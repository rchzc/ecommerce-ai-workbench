# 高转化标题撰写方法

## 一、标题结构（亚马逊为例）

推荐结构：`品牌名 + 核心关键词 + 关键属性 + 适用场景/人群 + 规格`

示例：
`Anker 无线充电板 15W 快充 适用于 iPhone 三星 安卓 带过充保护 黑色 2 片装`

## 二、撰写要点

### 1. 关键词前置
前 60 个字符权重最高，核心关键词必须放最前面。
移动端只显示前 60 字符左右，超出部分用户看不到。

### 2. 属性要具体
- 差：`高品质水杯`
- 好：`316 不锈钢保温杯 500ml 12 小时保温`

具体属性既是关键词，也是转化要素。

### 3. 避免堆砌
重复同一个词 3 次以上不会提升权重，反而影响可读性。
用同义词替换：`保温杯` / `保温水壶` / `不锈钢杯`。

### 4. 禁用词
- 绝对化用语：最好、第一、顶级（违反广告法）
- 促销信息：Sale、Free Shipping（平台会判违规）
- 主观宣称：100% 有效、永久（无法证明）

## 三、字符数控制

| 平台 | 建议长度 |
|------|---------|
| 亚马逊 | 150-200 字符 |
| TikTok Shop | 60-80 字符 |
| 独立站 | 60-70 字符（SEO 友好） |

## 四、A/B 测试

改标题后至少观察 14 天，对比指标：
- 曝光量（判断关键词覆盖是否变好）
- 点击率 CTR（判断标题吸引力）
- 转化率 CVR（判断标题是否误导）

**注意**：一次只改一个变量，否则无法归因。
