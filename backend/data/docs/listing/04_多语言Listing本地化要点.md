# 多语言 Listing 本地化要点

## 核心原则：不是翻译，是重写

直接机翻的 Listing 会有明显的中式表达，当地用户一眼看出，转化率极差。

## 各市场要点

### 英语（美/英/加/澳）
- 美式和英式拼写要区分（color / colour）
- 单位用当地习惯（美国用 inch / lb，欧洲用 cm / kg）
- 表达直接，强调功能和收益

### 德语（德国/奥地利）
- 用户最看重参数和认证，标题要包含具体规格
- 喜欢详细说明，五点可以写得比其他语种长
- 语法严谨，错误会严重影响信任度
- 注意：德国对环保和包装法要求严格（需注册 LUCID）

### 法语（法国）
- 表达偏优雅，避免过于直白的推销
- 强调设计和生活品质
- 法语有严格的空格规则（冒号前要空格）

### 西班牙语（西班牙/拉美）
- 拉美和西班牙的用词差异较大，尽量用中性表达
- 价格敏感度高，强调性价比
- 墨西哥站用拉美西语，不要用西班牙本土表达

### 日语（日本）
- 用户极度重视细节和服务，描述要非常具体
- 礼貌用语层级复杂，建议找母语者校对
- 强调品质、包装、配送速度
- 避免夸张宣传，日本人反感过度营销

## 本地化检查清单

- [ ] 单位换算正确
- [ ] 电源 / 电压符合当地标准
- [ ] 认证标识符合当地要求
- [ ] 没有中式直译表达
- [ ] 没有当地文化禁忌
- [ ] 尺码对照表已本地化
- [ ] 母语者校对过
